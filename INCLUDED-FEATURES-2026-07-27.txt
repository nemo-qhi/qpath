qpath complete all build - 2026-07-27

このZIPは、これまで追加した主要機能をまとめた全部入り版です。

含まれているもの:
- GitHub Pages向けの index.html / 404.html / .nojekyll
- GitHub Pagesの /q-path/ 配下で動く相対パス対応
- vendor配下のReact/Firebase/lucide依存ファイル
- Firebase Anonymous Auth / Firestore連携
- localStorageのバックアップ保存
- ホーム、クイズ、トーク、作問、プロフィール、教員ダッシュボード
- 下部ナビゲーションの「自習」から「トーク」への変更
- ロール選択、ニックネーム設定
- #role の専用URLから、保存済みの入室状態に関係なくロール選択を開始
- 教員の新規クラス作成、クラスコード生成、共有コードコピー
- 教員クラス作成時のパスワード設定
- 教員が既存クラスへ入室する導線
- 生徒がクラスコードで入室する導線
- 入ったことのあるクラスへ、利用者IDとクラスコードで再入室する導線
- クラスごとの利用者ID発行
- クラスコード入力画面内で「はじめて入る」「入ったことがある」を選択
- 初回入室後に、発行した利用者IDをコピーできる確認画面
- 再入室時はクラスコードと利用者IDを必須入力
- 教員の既存クラス入室時だけ先生用パスワードを表示
- 教員プロフィールで参加済み生徒の名前と利用者IDを確認
- クラスごとのプロフィール保存、名前・一言・アイコン色の編集
- クラス内で作成されたクイズは、そのクラス内でのみ表示/プレイ
- クイズ作成画面の教科選択
- 教科ごとの問題群フィルター
- 選択肢を押すと即時に正誤判定
- 「分からない」選択肢
- 不正解だった問題は最後に再出題され、正解するまで続く流れ
- 最後の問題で不正解だった場合も再挑戦できる修正
- 全問完了後にホームへ戻れる導線
- ブラウザ/画面内の戻る操作で空白やロール選択に飛びにくい安全戻り
- 謎の青い画面に飛ぶ問題への修正
- トーク画面の投稿、返信、顔文字リアクション
- 自分が作ったクイズのプロフィール表示
- 自分の利用者IDで作成したクイズの編集
- プロフィールの正答率、解いた数、作問傾向などの表示
- 教員ダッシュボードの現在入室中生徒カウント
