qpath トーク・プロフィールカード完全版

変更内容
- 投稿者のアイコンまたは名前をタップするとプロフィールカードを表示
- PCではホバーまたはキーボードフォーカスでも表示
- 名前、教員・生徒、一言、選択したアイコン色を表示
- リプライ投稿者にも同じプロフィール表示を追加
- カード外をタップすると閉じる
- 既に設定済みの一言・色をクラス名簿へ自動同期
- 学習履歴や正答率などの個人情報はカードに表示しない
- ホームボタン、開発者ノート、既存修正をすべて収録

GitHubへの反映
1. リポジトリ最上部で index.html を上書きします。
2. src フォルダで app.js、firebase.js、styles.css を上書きします。
3. Commit changes を押します。

README.txt とZIP自体はアップロード不要です。
